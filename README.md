Aqui va la descripción de cada base de datos.
Parkinsons Telemonitoring Dataset
Fuente: UCI Machine Learning Repository

Descripción:
Base de datos que contiene mediciones clínicas y vocales de pacientes con Parkinson.
Incluye variables como:

subject (ID del paciente), age, sex, test_time (tiempo en días del seguimiento), motor_UPDRS y total_UPDRS, 16 características vocales

Tamaño: 5875 registros, 19 columnas

Objetivo del dataset:
Monitorear la progresión de los síntomas motores a través de telemedicina.

Breast Cancer Wisconsin (Diagnostic) Dataset
Fuente: UCI Machine Learning Repository

Descripción:
Base con 30 variables numéricas obtenidas de imágenes de tejido mamario mediante Fine Needle Aspiration (FNA).
Clasifica tumores en:
M (Malignant) → maligno
B (Benign) → benigno

Tamaño: 569 registros, 30 columnas numéricas + columna objetivo

Objetivo del dataset:
Diagnosticar tumores como malignos o benignos a partir de características celulares.
